# 🥗 DietMaster – Kişisel Diyet ve Takip Sistemi

DietMaster, kullanıcıların beslenme planlarını takip edebildiği,
tarifler paylaşabildiği, görevlerle puan toplayabildiği ve
AI destekli danışmanlığa erişebildiği modern bir diyet takip uygulamasıdır.

📌 Bu proje şu anda geliştirme aşamasındadır ve **öğrencilik kapsamında**
değerlendirme amacıyla paylaşılmaktadır.

---

## 🚀 Özellikler

- 🧑‍⚕️ Diyetisyen – Danışan Rol Sistemi
- 🍽️ Tarif Paylaşımı ve Onay Mekanizması
- 🧩 Görevler ve Oyunlaştırma (Puan Sistemi)
- 🥇 Liderlik Tablosu (Günlük / Haftalık / Aylık)
- 🤖 AI Asistan ile Hızlı Diyet Sorguları
- 📅 Randevu Yönetimi
- 📊 Sağlık Karnesi Takibi
- 🎯 Modern UI (Bootstrap 5 + Custom Stil)

---

## 🛠️ Kullanılan Teknolojiler

| Alan | Teknoloji |
|------|-----------|
| Backend | Django 5 |
| Frontend | Bootstrap 5, HTMX |
| Authentication | Django Auth |
| Veritabanı | SQLite (Development) |
